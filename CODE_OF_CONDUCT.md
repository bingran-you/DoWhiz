# Code Of Conduct

## Our Standard

We want DoWhiz to be a repository where contributors can participate without being harassed, belittled, or excluded.

Examples of expected behavior:
- being respectful in technical disagreement
- giving actionable, evidence-based feedback
- welcoming first-time contributors
- assuming good intent while still being honest about problems
- focusing criticism on ideas, code, and behavior rather than people

Examples of unacceptable behavior:
- harassment, insults, or discrimination
- sexualized language or attention
- doxxing or sharing private information without permission
- sustained hostile argumentation
- trolling, intimidation, or bad-faith participation

## Scope

This code of conduct applies to:
- GitHub issues
- pull requests
- review comments
- linked community spaces used for project collaboration

## Enforcement

Project maintainers may remove comments, close threads, or restrict participation when behavior makes the project unsafe or unproductive.

If you experience or witness a serious problem, contact `admin@dowhiz.com`.

## Maintainer Responsibility

Maintainers should:
- set a respectful tone
- explain moderation decisions when practical
- protect contributors from abuse
- avoid using project authority to shut down good-faith technical disagreement
