## How To Read The Rest Of The Repo

Not all existing documentation was originally written for external contributors.

Treat these areas as secondary context unless a public doc sends you there:

- `reference_documentation/`: historical notes, third-party references, test plans, and architecture scratchpads
- `DoWhiz_service/OPERATIONS.md`: internal operational runbook
- `docs/*.md` files outside `docs/open-source/`: product or operational notes that may be historical or team-specific

The open-source onboarding path should start with `README.md`, `OPEN_SOURCE_SCOPE.md`, and the files under `docs/open-source/`.
